# 坦克大战 Tank Battle

纯 HTML / CSS / JavaScript 实现的经典坦克大战（Battle City 风格），无需任何依赖，打开即玩。

## 玩法

保卫金色鹰徽基地，消灭所有敌方坦克即可过关。基地被摧毁或生命耗尽则游戏失败。

- **移动**：`W A S D` 或 方向键
- **开火**：空格
- **暂停**：`P` 或 `Esc`
- 移动端会自动显示虚拟方向键和开火按钮

## 特性

- 3 个手工设计的关卡，通关后进入难度递增的多周目
- 4 种敌方坦克：普通（100 分）、快速（200 分）、火力（300 分）、装甲（400 分，需 4 发炮弹）
- 5 种道具（红色闪光坦克掉落）：
  - ★ 火力升级（满级炮弹可击穿钢墙）
  - 1UP 额外生命
  - 💣 全屏爆破
  - 护盾（10 秒无敌）
  - 冻结（敌人停止行动 8 秒）
- 砖墙可摧毁、钢墙坚不可摧、河流阻挡坦克、树林提供隐蔽
- WebAudio 合成音效、爆炸粒子效果、最高分本地保存
- 支持触屏设备

## 运行

直接用浏览器打开 `index.html` 即可，或启动一个静态服务器：

```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

然后访问 http://localhost:8000

## 部署到 GitHub Pages

仓库推送后，在 **Settings → Pages** 中选择分支和根目录，即可在线游玩。
